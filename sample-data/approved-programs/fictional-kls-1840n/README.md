# Fictional KLS-1840N approved-program corpus

FICTIONAL SAMPLE — NOT FOR MACHINE USE

This local-only dataset demonstrates governed historical-program analysis. Files
`eligible-01.nc` through `eligible-06.nc` are the compatible POST-A dataset.
`different-post.nc` uses POST-B, `deprecated.nc` is retained but excluded,
`unusual-ending.nc` deliberately uses M02, and `current-comparison.nc` omits
coolant-off and uses M02 to create explainable comparison findings.

Similarity to these fictional programs does not certify safety, correctness,
setup, post-processor behavior, or production readiness.
