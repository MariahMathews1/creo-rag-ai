# Pre-Azure Validation Workflow

With `POST_BUILDER_AI_PROVIDER=disabled`, users can create a Post Record, review knowledge/OFG requirements, apply standards, identify custom logic, export a package, record governed compilation/test work, parse a supported local listing, manage findings, prepare a VERICUT handoff, record external simulation and engineer review, and create versions.

Prefer fictional, synthetic, training, or explicitly approved qualification programs. Production part programs are never required. No validation action sends content to Azure.
