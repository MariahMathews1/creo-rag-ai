# VERICUT Handoff Workflow

`Prepare for VERICUT Validation` is a manual readiness view showing Post version, machine/controller, configuration issues, FIL review state, development package, and checklist state. It does not launch VERICUT or assume API, command-line, automation-server, or license access.

A `VERICUT Simulation` record stores result, operator/date, synthetic or approved test-program metadata, findings counts, and a local report/reference. VERICUT project geometry is not copied into the default package or AI context. A result is engineering evidence, not a safety guarantee.
