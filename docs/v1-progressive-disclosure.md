# V1 progressive disclosure

Technical controls remain close to their domain but outside the default task path:

- **Advanced Machine Details:** command policy and supporting metadata.
- **Technical Extraction Details:** confidence, authority, claim scope, excerpts, and proposal metadata.
- **Translation More / Technical Details:** alignment, validation, provenance, hashes, AI permission, and history.
- **Advanced Post Configuration:** templates, mappings, validation, versions, and technical readiness.
- **G-code Review Technical Details:** traceability and deterministic rule metadata.
- **Machine Assistant Technical Retrieval Details:** optional document-type and category constraints.

See [the advanced-feature inventory](v1-advanced-features.md).
