# V1 screen map

| Primary area | Main screens | Primary outcome |
| --- | --- | --- |
| Dashboard | `/` | Understand readiness and start common work |
| Machines | `/machines`, `/machines/new`, machine edit | Maintain programmer-facing machine context |
| Documents | `/documents` | Add and find machine technical evidence |
| Translation Examples | `/translations`, `/translations/:id` | Review known CL/G-code behavior |
| G-POST Generator | `/gpost`, `/gpost/:id` | Create and test an R&D post draft |
| Machine Assistant | `/machine-assistant` | Retrieve grounded machine-document answers |

Advanced routes remain supported for configuration history, extraction internals, alignment, provenance, validation, mappings, versions, reference programs, traceability, approved-standard comparison, and G-code Review.
