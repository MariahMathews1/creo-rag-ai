# V1 advanced features

Advanced capabilities are preserved but progressively disclosed.

- **Machines:** command policy, configuration history, reference programs, detailed extraction queues, proposal variants, confidence, and source metadata.
- **Translation Examples:** pattern analysis, AI experiments, alignment, hashes, provenance, AI-processing consent, validation details, and audit history.
- **G-POST Generator:** shared templates, mappings, validation internals, historical versions, technical readiness, CL trace, source excerpts, and raw evidence.
- **G-code Review:** deterministic findings, traceability, approved-program comparison, and technical rule identifiers.

Deterministic checks, immutable revisions, machine isolation, evidence provenance, and safety boundaries remain enforced throughout the product.
