# V1 Product Reduction

V1 is a focused post-development assistant for NC programmers. This reduction changes the visible product, not the retained research architecture.

The primary navigation is limited to Dashboard, Machines, Documents, Post Builder, and Machine Assistant. Machine setup leads to reviewed machine knowledge; Post Builder leads from a machine-specific foundation through OFG configuration, site standards, custom logic, review, versions, and sources.

Historical translation datasets, CL/G-code alignment, programmed-motion visualization, G-code analysis, diagnostic parsers, and prior AI experiments are not part of the normal V1 interface. Their backend models, APIs, tests, and research screens remain available for continued R&D.

No screen claims to generate a native G-POST option file, run G-POST, run VERICUT, simulate material removal, certify a program, or approve shop-floor use. Validation entries are records of work performed in approved external environments.
