# V1 Primary Workflow

1. Add or open a Machine.
2. Upload the machine and controller Documents.
3. Review Machine Knowledge and resolve missing or conflicting facts.
4. Create a Post from Post Builder. The three-step flow selects the machine, reviews available context, and names the Post Record.
5. Complete the Post workspace in this order: Machine Knowledge, OFG Configuration, Site Standards, and Custom Logic.
6. Use Review to resolve one outstanding queue and record G-POST tests, VERICUT checks, engineer review, and an optional dry run.
7. Create a Version and export the development package when the engineering record is ready for its controlled external workflow.

The Dashboard shows only Machines, Posts in Development, Needs Attention, Documents, recent Post work, and the three starting actions.
