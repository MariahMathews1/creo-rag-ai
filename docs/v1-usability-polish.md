# V1 usability polish

This milestone refines the existing NC-programmer workflow without expanding product scope. It standardizes action hierarchy and spacing, replaces disclosure-like action controls with application menus, makes machine incompleteness actionable, simplifies paired-code and toolpath review, and makes G-POST readiness specific to the submitted CL.

The deeper revision, alignment, mapping, validation, audit, and AI-governance architecture remains implemented under advanced disclosure.
