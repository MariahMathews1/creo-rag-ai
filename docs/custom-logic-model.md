# Custom Logic model

Custom Logic items record behavior that standard OFG configuration cannot adequately represent. Each captures reason, category, evidence, Site Standards, intended mechanism, status, reviewer notes, and optional source reference.

Statuses are Identified, Needs Information, Needs Draft, Drafted, Needs Review, Reviewed, Rejected, and Deferred. Specialist source editing belongs under Advanced Tools → FIL / CIMFIL Editor. Extension and naming remain **Site verification required** until locally validated.
