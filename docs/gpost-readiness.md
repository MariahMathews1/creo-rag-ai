# G-POST Readiness

Setup readiness requires an available immutable profile revision, matching profile/draft machine type, a compatible controller template family, a loaded base configuration, and either a relevant selected document or manual-configuration acknowledgement.

Review readiness is accepted required V1 mappings divided by all applicable required V1 mappings. Optional reference programs, programming standards, and advanced mappings are reported separately.

Preview is blocked for setup conflicts, unsupported-required behavior, machine-type snapshot mismatch, missing source acknowledgement, parser errors, or blocking deterministic findings. `GPOST_TEMPLATE_FAMILY_MISMATCH` blocks mill/lathe family conflicts; `GPOST_MACHINE_TYPE_SNAPSHOT_MISMATCH` identifies draft/profile disagreement.
