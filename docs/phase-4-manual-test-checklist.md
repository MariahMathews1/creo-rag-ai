# Phase 4 manual test checklist

1. Start services and run `alembic upgrade head`.
2. Run both seed commands and open the sample Traceability page.
3. Inspect parsed CL and G-code, then create an alignment.
4. Select records in both directions and inspect reasons.
5. Filter confidence bands and navigate unmatched records.
6. Confirm, reject, and annotate proposals.
7. Open the separate manual explanation and validation views.
8. Export Markdown, JSON, and CSV.
9. Replace a source and confirm old runs become stale.
10. Create a new version and compare summaries.
11. Restart and confirm runs, reviews, notes, issues, and versions persist.

Always verify the advisory notice remains visible.
