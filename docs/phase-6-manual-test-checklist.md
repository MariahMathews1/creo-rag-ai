# Phase 6 manual test checklist

- [ ] Import a reference program and confirm it starts pending/ineligible.
- [ ] Review machine revision, controller, post, part, operation, and hash.
- [ ] Parse and inspect deterministic validation.
- [ ] Explicitly mark one program eligible and another ineligible.
- [ ] Run standard extraction from compatible eligible programs.
- [ ] Confirm a different post revision is identified and not mixed.
- [ ] Inspect supporting and contradictory programs and exact lines.
- [ ] Accept a scoped convention and reject a weak convention.
- [ ] Confirm frequency alone never auto-accepts a proposal.
- [ ] Create an inactive standard draft.
- [ ] Explicitly submit and approve the standard.
- [ ] Compare a new program and confirm deterministic and convention findings
  remain separate.
- [ ] Classify an exception and confirm the standard is unchanged.
- [ ] Open a similar eligible reference and confirm its score is advisory.
- [ ] Inspect common, added, removed, and changed side-by-side sections.
- [ ] Export standard and comparison reports in JSON, Markdown, and CSV.
- [ ] Restart the app and confirm programs, standards, reviews, and comparisons
  persist.
- [ ] Change program eligibility or applicability and confirm stale warnings.
- [ ] Confirm every result says historical similarity is not certification.
- [ ] Confirm programs with `ai_processing_allowed=false` use no external AI.
