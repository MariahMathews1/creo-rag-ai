# V1 NC programmer workflow

The normal sequence is:

1. Add the CNC machine and controller context.
2. Attach machine-specific manuals and references.
3. Ask Machine Assistant questions grounded in those documents.
4. Add known Creo CL/NCL and historical G-code as Translation Examples.
5. Inspect Paired Code and Toolpath without managing alignment internals.
6. Select the machine in G-POST Generator, confirm post context, and create a draft.
7. Paste or upload CL/NCL, generate an R&D draft, and inspect results and toolpath.
8. Use G-code Review contextually for an existing program or detailed finding review.

See [the full workflow guide](v1-product-workflow.md).
