# V1 action hierarchy

- **Primary:** the main task, such as Generate G-POST Draft.
- **Secondary:** direct supporting tasks, such as Find in Documents or Open Machine.
- **Tertiary/menu:** lower-frequency actions grouped under More or Advanced.
- **Text action:** low-emphasis navigation inside content.
- **Danger:** destructive actions separated at the bottom of an action menu.

Dashboard keeps one primary generation CTA. Machine cards expose Generate, Find Information, and Open Machine directly; edit, history, reference programs, and deletion are grouped under More.
