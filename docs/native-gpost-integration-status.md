# Native G-POST integration status

**Status: Not Verified**

The application produces reviewed engineering configuration data and Post Development Packages. It does not generate a proprietary native G-POST `.opt` file.

Direct OFG import/export, editable/compiled formats, naming, compiler flow, and deployment behavior require validation against the site's installed PTC/Creo G-POST environment. Final entry, compilation, controlled testing, and implementation remain in the approved environment.
