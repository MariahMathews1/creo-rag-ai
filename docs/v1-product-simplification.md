# V1 product simplification

The V1 pass makes the NC programmer's job—not the internal architecture—the organizing principle. Primary screens focus on machine setup, machine documents, known CL/G-code pairs, post generation, toolpath inspection, and contextual review.

The backend trust model is unchanged. Immutable machine configurations, deterministic validation, traceability, translation alignment, consent enforcement, G-POST mappings, and audit/version history remain implemented. They are exposed when needed through Advanced, Technical Details, More, History, and Evidence controls.

See [the reduction decisions](v1-ui-reduction-decisions.md) for the detailed rationale.
