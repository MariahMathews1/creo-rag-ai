# V1 NC programmer workflow

The V1 product is organized around six daily tasks:

1. **Dashboard** — check machine, document, translation-example, draft, review, and blocking-finding status.
2. **Machines** — add a CNC machine, maintain practical programming limits and controller context, and extract machine information from documents.
3. **Documents** — upload manuals, specifications, procedures, and reference material for one machine.
4. **Translation Examples** — add known Creo CL/NCL and historical G-code pairs, review paired code and toolpath, and verify trustworthy evidence.
5. **G-POST Generator** — select a machine, confirm post context, create a draft, provide CL/NCL, generate R&D output, and inspect results and toolpath.
6. **Machine Assistant** — ask machine-specific questions grounded in the selected machine's uploaded documents.

G-code Review is under **Advanced / Engineering Tools**. Generated output remains R&D-only and requires qualified review, simulation, and controlled approval.
