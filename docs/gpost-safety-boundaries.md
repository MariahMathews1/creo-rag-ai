# G-POST safety boundaries

Every G-POST screen, preview, and export is labeled:

> R&D ONLY · NON-PRODUCTION · NOT VALIDATED FOR MACHINE USE

The feature does not execute machine code, connect to Creo, connect to a CNC, certify controller behavior, simulate motion, prove collision freedom, or silently approve a post. Generated text is advisory and may be incomplete or wrong.

Unknown machine capability is displayed as unknown; it is never invented. Document citations are stored only when backed by an uploaded, machine-owned source. Approved-program recurrence and organizational standards are presented separately from controller documentation and deterministic findings.

Qualified post developers and manufacturing engineers must verify the exact machine, options, control revision, parameterization, builder M-codes, tooling, workholding, post behavior, simulation, and controlled approval process outside this proof of concept.
